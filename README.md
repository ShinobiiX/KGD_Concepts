# KGD CONCEPTS — DIGITAL PORTFOLIO

> **"Ideas conceived. Technology crafted. Experiences delivered."**

Official digital portfolio and interactive studio showcase for **KGD Concepts**, an independent digital technology brand operating across software development, artificial intelligence, workflow automation, cybersecurity, and digital design.

---

## ✦ Overview

This portfolio showcases selected production applications, contributed initiatives, and continuous research labs:

* **CANARY:** AI security assessment platform designed to demonstrate adversarial testing, experiment evaluation, risk scoring, and research reporting through deterministic simulations.
* **Nexa AI:** AI & Web3 exploration platform focusing on accessible AI utilities, DeFi tools, and 3D polyhedral visualizations.
* **Nexa Corp:** Web3 growth and strategic positioning firm platform.
* **The Faves Academy:** Educational web application featuring learning resources, class booking, and administration.
* **Nth Jobs:** Automated job discovery, aggregation, and workflow pipeline built with n8n (*In Development*).

## 🛠 Tech Stack

* **Core Framework:** [React 18](https://react.dev/)
* **Build Tool:** [Vite 6](https://vitejs.dev/)
* **Language:** Modern JavaScript (ES Modules)
* **Styling:** Modular Component CSS with CSS Custom Properties, hardware-accelerated 3D CSS transforms (`perspective`, `rotateX/Y`, `translateZ`), and glassmorphism
* **Icons:** [Lucide React](https://lucide.dev/)
* **Typography:** Space Grotesk, Plus Jakarta Sans, JetBrains Mono

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.0 or newer)
* npm, pnpm, or yarn

### Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/ShinobiiX/kgd-concepts-portfolio.git
cd kgd-concepts-portfolio
npm install
```

### Development Server
Run the local Vite development server with hot-module replacement (HMR):

```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
Build optimized production static assets:

```bash
npm run build
```
Preview the production build locally:

```bash
npm run preview
```
